# Project 01 - File Integrity Monitoring using Wazuh

## Objective
Monitor file creation, modification, and deletion on a Windows endpoint using Wazuh File Integrity Monitoring (FIM).

## Lab Environment
- Wazuh SIEM
- Ubuntu Server
- Windows 10 Agent
- VirtualBox

## Steps Performed
1. Installed and configured Wazuh.
2. Connected the Windows agent.
3. Enabled File Integrity Monitoring.
4. Created, modified, and deleted test files.
5. Verified alerts in the Wazuh dashboard.

## Detection Results
- File Created
- File Modified
- File Deleted
