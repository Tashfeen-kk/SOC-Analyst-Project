# Nmap Network Scan Detection Documentation

## Purpose

This project demonstrates how Wazuh SIEM can be used to investigate security events generated during an authorized Nmap network scan in a home lab.

---

## Technologies Used

- Wazuh SIEM
- Kali Linux
- Windows 10
- Ubuntu Server
- VirtualBox
- Nmap

---

## Test Procedure

1. Verify Wazuh Agent connectivity.
2. Launch an authorized Nmap scan from Kali Linux.
3. Monitor security events.
4. Review alerts in the Wazuh Dashboard.
5. Document the investigation.

---

## Detection

- Security events collected
- Alerts reviewed in Wazuh
- Event timeline analyzed

---

## Skills Learned

- Wazuh SIEM
- Nmap
- Network Reconnaissance Analysis
- Threat Hunting
- Incident Investigation

---

## Outcome

The project demonstrated how Wazuh can centralize and support investigation of security events associated with authorized network reconnaissance in a controlled lab environment.
